Allow customers to change product quantities and remove products directly from both Classic and Block-based WooCommerce checkout pages.

== Description ==

This lightweight plugin enhances the WooCommerce checkout experience by enabling quantity updates and product removal options directly on the checkout page.

= Key Features =

**Quantity Management**: Add WooCommerce standard quantity fields directly on the checkout page.
**Product Removal**: One-click product deletion from checkout.
**Dual Compatibility**: Supports both **Classic and Block-based** WooCommerce checkout.
**Seamless Integration**: Uses native WooCommerce styling and functionality.
**Mobile Friendly**: Responsive design that works on all devices.

**Note on Compatibility**: This plugin works with the default WooCommerce quantity input. If your theme replaces or customizes the quantity selector (e.g., with plus/minus buttons), the functionality may not work as expected.

= Important Compatibility Note =

This plugin is designed to work exclusively with the standard WooCommerce Checkout page (including the new Checkout Blocks and the Classic shortcode). It is not compatible with custom checkout pages built using third-party page builders like:

* Elementor (WooCommerce Builder)

* Divi BodyCommerce

* WooLentor / CoBlocks

= Perfect For =

* Stores wanting to reduce checkout abandonment.
* Improving user experience by removing the "back to cart" step.
* Modern WooCommerce stores using block-based checkout.


== Installation ==

= Automatic Installation =

1. Log in to your WordPress admin panel
2. Navigate to Plugins > Add New
3. Search for "Change Quantity on Checkout for WooCommerce"
4. Click "Install Now" and then "Activate"

= Manual Installation =

1. Ensure you have the latest version of WooCommerce plugin installed
2. Download the plugin zip file
3. Upload and extract contents to your /wp-content/plugins/ directory
4. Activate the plugin through the 'Plugins' menu in WordPress
5. Go to CQOC menu and enable the plugin functionality

== Frequently Asked Questions ==

= Does this work with WooCommerce Checkout Blocks? =
Yes! Version 4.0 added full support for the new WooCommerce Block-based checkout. It also works perfectly with the traditional Classic checkout page.

= Can I use it with High-Performance Order Storage (HPOS)? =
Yes, the plugin is fully compatible with WooCommerce HPOS (High-Performance Order Storage), ensuring your store remains fast and future-proof.

= Does it work with my theme's quantity buttons? =
This plugin is built to work with the native WooCommerce quantity input. If your theme uses custom plus/minus buttons or a heavily modified UI, it may require CSS adjustments. The Pro version includes broader compatibility for custom themes.

= Does it work with custom Checkout Page Builders? =
This plugin is designed to work exclusively with the standard WooCommerce Checkout page (including the new Checkout Blocks and the Classic shortcode). It may not function correctly with custom checkout pages built using third-party page builders like Elementor, Divi, or WooLentor.

= Does it support Product Variations? =
Yes. If a customer adds a "Blue - Large" shirt to their cart, the plugin will correctly display and update that specific variation directly on the checkout page.

= Is it mobile responsive? =
Absolutely. The quantity fields and remove buttons are designed to be touch-friendly and look great on iPhones, Androids, and tablets.

= How do I upgrade to the Pro version? =
You can find the "Change Quantity on Checkout Pro" version at navonmeshsolution.com. It includes features like category-specific filters and AJAX-powered instant updates.
